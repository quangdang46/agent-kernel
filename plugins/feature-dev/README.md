# Feature Dev Plugin

Install this pack when you want the `agent-kernel` feature workflow as a standalone Claude Code plugin.

It includes:

- `skills/feature-development`
- `skills/spec-review`
- `agents/code-explorer.md`
- `agents/code-architect.md`
- `agents/code-reviewer.md`
- `agents/spec-reviewer.md`

Use this pack for multi-file feature work that benefits from a deliberate flow instead of direct implementation.
